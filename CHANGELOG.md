# Changelog

All notable public protocol changes will be recorded here.

## [Unreleased]

### Added

- Broker decision CLI validation via `sovereignty validate --schema broker-decision`.
- Public broker decision JSON fixtures for privacy reject, authority reject, price-selected, and fallback-selected paths.

## [0.1.0] - 2026-07-09

### Added

- First public protocol release under the PyPI distribution name `sovereignty-protocol`.
- Review packet, exposure, measured exposure, telemetry, side-effect proposal, policy, guardrail, lane-health, exposure-budget, and broker-decision contracts.
- Metadata redaction helpers and CLI utilities.
- Hermes local-router adapter example with measured exposure evidence and broker decision output.
- Trusted Publishing release workflow for TestPyPI and PyPI.
